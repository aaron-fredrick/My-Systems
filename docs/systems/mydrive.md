# ☁️ MyDrive

## Own your storage.

MyDrive is the planned personal cloud and file platform for running storage on hardware you control.

## Scope

- File storage and management
- Device synchronization
- Sharing
- Remote access
- Versioning where appropriate
- Storage management
- Integration with MyBackup

## Deployment

The intended model is flexible: repurposed laptop, desktop, mini PC, home server or VM.

## Ecosystem Role

MyDrive provides active user storage. **MyBackup remains a separate recovery system** responsible for snapshots, retention and restoration.
