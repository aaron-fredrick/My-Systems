# 🔐 MyVault

## Own your secrets.

MyVault is the planned personal secrets platform for passwords, API keys, service credentials and sensitive notes.

## Scope

- Passwords and credentials
- API keys and tokens
- Secure notes
- Encryption
- Access control
- Secret lifecycle management
- Integration with MyAuth where appropriate

## Security

Secrets should never be committed to source control. MyVault is intended to become a dedicated security boundary rather than a general-purpose database.
